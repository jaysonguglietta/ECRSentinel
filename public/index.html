One-time export setup

An AWS administrator must first provide a private S3 bucket, a customer-managed KMS key, and export permissions. A read-only role cannot create these resources or call inspector2:CreateSbomExport without an additional grant. If the role must stay strictly read-only, this workflow cannot start.

What to ask your AWS administrator

Provide an approved Inspector SBOM export bucket and KMS key in this Region. Grant this role Inspector export and scoped S3/KMS read permissions.

AWS export guide

Set up an approved export destination first.
Access and export requirements

The image must be active and monitored by Inspector Enhanced Scanning. An administrator must grant inspector2:CreateSbomExport and inspector2:GetSbomExport, scoped S3 read access, and KMS decrypt access to the selected role. Inspector needs write access to the bucket and encryption key. A strictly read-only role cannot start this export, even with a saved destination.
